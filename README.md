### Compliance Checker — AI-Powered RAG System

* Developed an **AI-powered contract compliance checker** using **RAG, LangChain, FAISS, Hugging Face embeddings, and Google Gemini**.
* Built a **Streamlit interface** supporting individual rule checks and full compliance audits across **16 predefined contract rules**.
* Implemented document preprocessing, semantic retrieval, evidence extraction, compliance classification, and **AI-generated remediation suggestions**.
* Designed the system to analyze contract content and return **COMPLIANT/NON-COMPLIANT results with supporting evidence**.
